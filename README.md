# The Workshop Co. — Product Landing Page

A minimal, black & white handcrafted product landing page.

## Folder Structure

```
LAURA FANCY STORE/
├── index.html          # Main entry point
├── README.md           # Project documentation
└── assets/
    ├── css/
    │   └── style.css   # All styles
    ├── js/
    │   └── script.js   # Interactions & animations
    └── images/         # Drop images here (product photos, etc.)
```

## Running Locally

```bash
cd "LAURA FANCY STORE"
python3 -m http.server 5500
```

Then open → http://localhost:5500
